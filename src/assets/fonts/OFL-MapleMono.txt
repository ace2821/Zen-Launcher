Two notes a future maintainer will want:

1. In @fontsource/maple-mono@5.3.0 the `-500-` and `-600-` files are swapped: the
   file published as `500-normal` contains the SemiBold instance (OS/2
   usWeightClass 600) and the file published as `600-normal` contains the Medium
   instance (usWeightClass 500) — confirmed from the font's own OS/2 table and
   from the "H" stroke ink area measured on each instance. The vendored files
   above are therefore named after the weight they actually contain, so the file
   name, the `font-weight` in styles/fonts.css and the glyphs all agree.

2. Fontsource ships Maple Mono as a single subset labelled `latin`. That file
   already contains the latin-ext codepoints Polish needs (ą ć ę ł ń ó ś ź ż and
   friends) — verified against the font's cmap — so there is no separate
   latin-ext file to fetch, and styles/fonts.css declares no unicode-range for
   these faces.
