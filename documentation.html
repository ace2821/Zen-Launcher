Overview

Zen Launcher is a local-first game library manager and launcher for Linux. It organizes, launches and mods the games you already own — DRM-free store purchases, freeware, plain game folders and Windows titles through Wine. There are no store clients, no accounts and no telemetry.

Network access is limited to metadata providers (Steam, SteamGridDB, ScreenScraper) and an optional update check — both are toggleable and all results are cached locally.

Platform: Linux first (Arch / CachyOS dev target). Windows port is planned but not yet available.

Quick Start

  1. Download: grab the AppImage from the Downloads page.
  2. Make executable: chmod +x "Zen-Launcher-1.1.0-x86_64.AppImage"
  3. Run: ./"Zen-Launcher-1.1.0-x86_64.AppImage"
  4. Add games: point the launcher at your game folders; it scans and suggests candidates for approval.

Library Management

Scan any folder you point Zen Launcher at. The scanner detects engines (Unity, Godot, Unreal, GameMaker, plain executables) and produces candidates with confidence scores. You approve, edit or reject each one.

  • Cover art via Steam search with monogram fallbacks
  • Playtime and recents tracking
  • Favorites, notes, tags, hiding
  • Metadata from Steam, SteamGridDB, ScreenScraper and local files
  • Cover grid (default) and list/table views

Launch & Wine

Each game has its own launch profile: executable, arguments, working directory and environment variables. Windows titles run through system wine with a managed prefix per game (~/.local/share/zen-launcher/prefixes/<game id>), so unrelated games never share a registry or C: drive.

  • Per-game WINEPREFIX / WINEDLLOVERRIDES overrides
  • GameMode and MangoHud toggles
  • Every session is recorded with duration and exit code
  • Multiplayer clients: SA-MP (host/port/nick), FiveM, MTA badges
Known limitation: only the direct child process is supervised. Wrapper-style launchers that exit immediately may end the session early.

Mods

Zen Launcher detects what a game runs and can install downloadable loaders straight from GitHub releases. Detected loaders include BepInEx 5/6, MelonLoader, NeoModLoader, MSC Mod Loader, tModLoader, CLEO 5/4 & Redux, Script Hook IV/V and Frosty.

  • Manual-install loaders get official-page links instead
  • Mod archives (zip / 7z / rar) can be dropped onto a game
  • Archives are unpacked into the loader's mods folder with redundant-file handling
  • Loaders Zen installed can be checked for updates and reinstalled
  • Non-destructive: enable/disable moves files to a stash, never deletes

Configuration

Settings live in ~/.config/zen-launcher/config.toml (mode 0600 for provider keys). Library data lives in ~/.local/share/zen-launcher/ (library.db, images/, saves/, mods/).

First-run wizard

  • Language: English + Polish from day one
  • Font: Maple Mono (default), headings in Space Grotesk
  • Accent presets and default library view
  • Dark theme only for now — light theme deferred
  • Wizard is skippable and re-runnable from Settings

Saves

  • Auto-backup before each session (if enabled) + manual backup
  • Versioned ZIP snapshots per game
  • One-click restore with pre-restore safety copy
  • Save path auto-detection or user-defined per game

FAQ & Troubleshooting

Does it telemetry?

No. Network is only used for chosen metadata providers and the update check, both toggleable.

Windows games won't launch?

Make sure wine is installed. Each Windows game gets its own prefix; if a prefix is corrupt, recreate it from the game's launch options.

Desktop integration broken?

Download the .desktop file from the Downloads page and place it in ~/.local/share/applications/, then adjust the Exec path to point at your AppImage.

Where are logs?

In ~/.local/share/zen-launcher/logs/.
