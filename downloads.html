Download Zen Launcher directly from this site — no GitHub account or releases page needed. If desktop integration doesn't work out of the box, grab the .desktop file below and place it in ~/.local/share/applications/.

Zen Launcher AppImage

Works on any glibc-based distro. Includes the full Tauri 2 application (Rust core + WebView UI). Version 1.1.0, x86-64.

Zen-Launcher-1.1.0-x86_64.AppImage ≈ 112 MB
Download AppImage 
chmod +x "Zen-Launcher-1.1.0-x86_64.AppImage"

.desktop file

Desktop entry for KDE / GNOME / Xfce menus. Use this if launcher integration doesn't work automatically. Place it in ~/.local/share/applications/ and adjust the Exec path to your AppImage location.

zen-launcher.desktop
Download .desktop 
# Install to applications menu
cp zen-launcher.desktop ~/.local/share/applications/
update-desktop-database ~/.local/share/applications/
Prefer GitHub Releases? The same files are also published on GitHub Releases. Direct downloads here are a convenience mirror.

Install after download

# 1. Make the AppImage executable
chmod +x "Zen-Launcher-1.1.0-x86_64.AppImage"

# 2. Run it
./"Zen-Launcher-1.1.0-x86_64.AppImage"

# 3. (Optional) Install .desktop for menu integration
cp zen-launcher.desktop ~/.local/share/applications/
update-desktop-database ~/.local/share/applications/
